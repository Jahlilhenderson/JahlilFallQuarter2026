1. What is Git, what is Github, and what is the difference between the two?

Git is a version control where you can tract changes in your code. While Github is a website built to help store and collaborate on that code.

2. What is the difference between a local repository and a remote repository?

A local repository is a file that is physical and stored on the electronic. A remote repo is stored on the cloud and online.

3. What does the push command do in Git?

the push command allows you to upload the changes on your local repo to your remote repo

4. What does the commit command do in Git?

the commit command saves the changes on your local repo 

5. What is Github Desktop, & why are we using it?

The github desktop is an app that allows easy access to other git websites.
